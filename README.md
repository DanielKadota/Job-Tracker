# Job Tracker

Aplicação web desenvolvida para organizar e acompanhar candidaturas a vagas de emprego, utilizando HTML, CSS e JavaScript.

**Status:** Em desenvolvimento.

## Sobre

O Job Tracker tem como objetivo centralizar o gerenciamento de candidaturas, permitindo registrar oportunidades, atualizar informações e acompanhar o andamento dos processos seletivos por meio de um dashboard.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Cadastro de candidaturas.
- Edição e exclusão de registros.
- Pesquisa por cargo ou empresa.
- Gerenciamento do status das candidaturas.
- Dashboard com indicadores de candidaturas.
- Interface responsiva.

## Conhecimentos aplicados

- Estruturação com HTML semântico.
- Estilização e responsividade com CSS.
- Manipulação do DOM.
- Eventos e formulários em JavaScript.
- Criação dinâmica de elementos HTML.
- Manipulação de arrays e objetos.
- Utilização dos métodos `forEach()`, `filter()`, `findIndex()`, `push()` e `splice()`.

## Próximas melhorias

- Implementar persistência de dados com LocalStorage.
- Desenvolver filtros por status.
- Aprimorar a experiência de pesquisa.
- Melhorar o gerenciamento de estados vazios.
